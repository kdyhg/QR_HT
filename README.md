# QR_HT

하트와 별 모양 장식을 더한 QR 코드 생성기입니다.

## 주요 기능

- 기본 사각형, 하트, 각진 별 모양 QR 생성
- QR 본체와 주변 장식이 자연스럽게 이어지는 연결형 실루엣
- URL 자동 보정 및 형식 검증
- 색상 대비 경고
- 생성 결과의 QR 스캔 가능 여부 자동 검증
- 같은 URL과 모양에서 재현 가능한 장식 패턴
- `장식 바꾸기`로 대체 패턴 생성
- PNG 저장 및 클립보드 복사
- QR 생성/검증 라이브러리 로컬 포함

## 사용 방법

`index.html` 파일을 브라우저에서 열면 바로 사용할 수 있습니다.

GitHub Pages에 배포하려면 저장소 Settings의 Pages 메뉴에서 배포 브랜치를 지정하면 됩니다.

## 파일 구조

- `index.html`: 앱 UI와 QR 생성 로직
- `vendor/qrcode.min.js`: QR 생성 라이브러리
- `vendor/jsQR.js`: QR 검증용 디코더
- `vendor/*-LICENSE.txt`: 포함된 라이브러리 라이선스

## 스캔 안정성

하트와 별 장식은 QR 본체를 직접 변형하지 않고, QR 외곽에 바로 맞닿도록 그려져 하나의 실루엣처럼 보입니다. 생성 후 브라우저에서 디코딩을 시도해 스캔 가능 여부를 표시합니다.

스캔이 실패하면 배경은 밝게, QR 색상은 어둡게 조정하거나 `장식 바꾸기`를 눌러 새 패턴을 만들어보세요.
